# Reproducible analysis code for JRSI FoG study

This repository contains the reproducible analysis code used to generate the figures and tables reported in the manuscript:

**“A Regime-Dependent Cortical Control Account of Freezing of Gait”**

submitted to the *Journal of the Royal Society Interface*.

## Contents

- `doorway_code_release.zip`  
  Self-contained archive with all analysis scripts and instructions required to reproduce the reported results.

## Usage

The code is designed to be run via a single entry point with a command-line interface.
Detailed instructions are provided inside the archive.

Two data access modes are supported:
- Local dataset access
- Zenodo-based dataset access (for reviewers)

## Data availability

The raw dataset is publicly available:
- Li et al. (2021), Multimodal Dataset of Freezing of Gait in Parkinson’s Disease

Derived outputs (figures and tables) are fully reproducible from this code.

This repository is provided for **reproducibility and verification**.
It is not intended as a clinical tool, predictive model, or intervention framework.
